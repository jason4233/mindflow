# MindFlow 功能規格（GitMind 複刻）— v1.0

> 事實來源：docs/research/（DIGEST 為濃縮版；衝突時以 ADDENDUM 為準）+ LIVE_DOM_FACTS.md（主 session 實測）。
> 原則：功能、佈局、快捷鍵、視覺參數對齊 GitMind；代碼與素材全部原創；產品名 MindFlow。

## 0. 範圍

- **v1 = 心智圖編輯器 + 首頁儀表板**。
- 延後：流程圖編輯器、白板模式（ADDENDUM 發現的獨立模組）、多人協作後端、評論後端、思想星球、AI 創作後端（介面層先做，可設定 OpenAI-compatible API）。
- 本機模式（localStorage），無登入牆。

## 1. 快捷鍵總表（= 驗收清單，照官方）

節點：`Tab` 插入下級｜`Enter` 插入同級｜`Shift+Tab` 插入上級（原節點變成新節點的子）｜`Ctrl+/` 展開/收合｜`Delete` 刪除含子樹｜`Ctrl+Delete` 刪除但保留子節點（子節點上移遞補）｜`Alt+↑`/`Alt+↓` 同級上移/下移｜`Ctrl+左鍵拖曳` 框選多選｜`Ctrl+點擊` 逐一多選｜`Shift+↑`/`Shift+↓` 選取上/下同級｜`Ctrl+Alt+C`/`Ctrl+Alt+V` 複製/貼上節點樣式｜`Ctrl+D` 複製節點（duplicate）

基本：`Ctrl+Z` 復原｜`Ctrl+Y` 重做｜`Ctrl+C/V/X` 複製/貼上/剪下｜`Ctrl+S` 儲存

樣式：`F6` 換主題（循環下一個）｜`Ctrl+P` 開主題面板｜`Alt+Y` 開樣式面板

文字：`Space` 進入編輯（選中節點時）｜`Shift+Enter` 節點內換行｜`Ctrl+B/I/U` 粗/斜/底線｜`Ctrl+G` 格式刷｜`Ctrl+1..9` 優先順序圖示｜`Ctrl+Shift+>` / `Ctrl+Shift+<` 字級加/減

插入：`Ctrl+Alt+K` 連結｜`Ctrl+Alt+M` 備註｜`Ctrl+Alt+T` 概要｜`Alt+P` 圖片｜`Alt+I` 圖示｜`F4` 關聯線｜`Ctrl+Alt+R` 評論（佔位）

畫布：`Ctrl+0` 重設縮放 100%｜`Ctrl+滾輪` 縮放｜`Ctrl+Shift+L` 一鍵整理｜`Ctrl+O` 大綱視圖切換｜`左鍵拖曳空白` 平移畫布｜`F11` 全螢幕｜`Ctrl+Alt+F` 適應畫布｜`Ctrl+Shift+R` 置中回主主題｜`Ctrl+F` 尋找&取代｜`Ctrl+A` 全選｜`Esc` 退出專注/演示模式

進階：`Shift+Alt+H` 歷史版本｜`Shift+Alt+F` 懸浮節點

**明確不存在**（不要實作成快捷鍵）：F2 編輯、純方向鍵導覽。

## 2. 編輯器 UI Chrome

- 頂部工具列 = **三個獨立白色圓角膠囊區塊**懸浮於畫布上（非通長 bar）：
  - 左：返回箭頭｜檔名（點擊改名）｜自動儲存時間戳（「已保存 HH:MM」）
  - 中（13 顆圖示）：復原｜重做｜加下級｜加同級｜加上級｜格式刷｜文本T｜插入⊕（下拉：圖片/連結/備註/公式/評論/貼紙）｜概括｜關聯線｜魔杖（主題）｜演示模式｜AI（佔位選單）
  - 右：分享（橘色藥丸按鈕）｜匯出｜更多 `···`
- `···` 選單：專注｜團隊協作（佔位）｜尋找&取代｜歷史版本｜一鍵整理｜顯示評論 toggle｜快速鍵（開快捷鍵面板）｜設定｜底部顯示「評論數/節點總數」
- 右側面板（選中節點或點魔杖開啟）4 分頁：**樣式 Style｜主題 Theme｜佈局 Layout｜圖示 Icon**
- 右下角控制群：檢視模式下拉（心智圖/大綱/大綱+心智圖）｜縮小｜縮放%｜放大｜手形工具 toggle｜全螢幕｜小地圖 toggle（導航器：紅框拖動視野）
- 節點右鍵選單：添加上級/同級/下級節點｜選擇›｜插入›｜分解（=刪除但保留子節點）｜複製｜黏貼｜刪除｜刪除當前節點(Ctrl+Delete)
- 畫布右鍵選單：一鍵整理｜展開/收起›｜全選｜懸浮節點｜歷史版本｜尋找&取代｜更多›
- 文字浮動工具列（編輯文字時出現在節點上方）：字型｜字級｜B/I/U/S｜文字色｜反白色｜對齊｜行距｜格式刷（支援選取局部文字格式化）
- 品牌主色 `#F17E2E` 橘；工具列膠囊白底、陰影 subtle。

## 3. 樣式面板（Style 分頁控制項，由上到下）

1. `形狀 Shape`：10 種（小圓角矩形/大圓角矩形/窄藥丸/寬藥丸/更大圓角矩形/底線 underline/圓形/橢圓/菱形/平行四邊形）+ 填色
2. `圓角 Radius`：滑桿+數值，預設 6px
3. `邊框 Border`：線型 5 種（實線/細點虛線/中段虛線/點劃線/長虛點劃線）+ 顏色 + 寬度 0–5px 六階
4. `連接線 Line`：形狀（曲線/直線/直角）+ 顏色 + 線型 5 種 + 寬度 0–5px（預設 3px）
5. `結構 Structure`：單節點局部佈局方向（預設 Right）
6. `節點間距`：水平/垂直滑桿（預設 30/30）+ 適用範圍下拉（預設「所有節點」）
- 色票元件（全站共用）：10 欄色相 × 7 列深淺 + 預設 + 最近使用 + 更多顏色

## 4. 主題與背景（Theme 分頁）

- 子分頁：`主題`｜`背景`
- 主題：縮圖網格；推薦區（可釘選最多 6 個、可設為預設）；自訂區。**至少 12 個內建主題**，涵蓋官方三情境：深色系（簡報）、日記筆記風、繽紛多彩系。主題資料結構：`{id, name, canvasBg, rootStyle, branchPalette[], levelStyles[], lineStyle, rainbowBranches:boolean}`
- 已確認的真實主題樣本（LIVE_DOM_FACTS）：粉紅背景 `#FDE0DC` + 根節點淡藍 `#DAEEF3` + Office 調色盤分支（#7030A0/#E36C0A/#00B050/#92D050/#00B0F0/#002060/#4BACC6）+ 線寬 4→3→2→1 遞減 + 二級文字=分支色 + 末端底線式
- 其他主題方向（THEMES.md）：水彩薄荷綠、極簡淺藍、秋色暖棕橘、奶油塗鴉、藍橘雙色藥丸 outline、灰階黑白 outline、深色星空（`#0B0B2A` 底）、紫紅彩虹
- 背景子分頁：隨機背景按鈕｜5 色快選+色票｜推薦背景庫（漸層/紋理，原創產生）｜浮水印勾選
- 浮水印：文字上限 30 字（預設「MindFlow」）、顏色、旋轉 3 選項（左斜/右斜/水平）、透明度 0–100、字級

## 5. 佈局（Layout 分頁）

6 種全域佈局：①心智圖（中心發散，左右自動平衡）②邏輯結構圖（向右層疊；含向左變體）③時間軸（水平/垂直）④組織結構圖（向下）⑤目錄結構圖（縮排樹）⑥魚骨圖。切換動畫平滑過渡。單節點可用 Structure 局部覆蓋方向。

## 6. 核心編輯行為

- 拖曳節點 → 橘色指示標記顯示可放置位置；放到節點上=成為其子節點；可拖到根另一側。
- 節點寬度：拖節點左右邊緣調整；多選可批次調寬。
- 摺疊鈕：分支外側小圓圈，摺疊時顯示 `+N`（隱藏後代數）。
- 懸浮節點：不掛在樹上的自由節點，可拖到樹上掛接。
- 關聯線：F4 或按鈕 → 點目標節點 → 產生虛線曲線；選中出現黃色控制點可調弧度與端點；Space 編輯線上文字；樣式面板可改線型/色/粗細。
- 概要（概括）：選同父的連續同級節點 → 產生右側大括弧+概要節點；可拖曳黃色邊界調整涵蓋範圍；樣式可調。
- 備註：節點加 📄 圖示，點擊開右側備註編輯欄。
- 連結：自動偵測貼上的 URL；hover 顯示 tooltip；右鍵移除。
- 圖片：上傳/拖放/貼上，內嵌 base64，選中可拖角調整大小。
- 圖示：分類=優先順序（數字彩色圓標 1-9）/進度（圓餅 0-100%）/旗幟/表情/符號；同類互斥替換，異類並存；再點同一圖示移除。
- 格式刷：複製來源節點全部樣式 → 游標變刷子 → 點目標套用（單次）。
- 尋找&取代：Ctrl+F 浮動小窗，逐一跳轉高亮 + 全部取代。
- 公式：LaTeX 子集輸入 → 節點內渲染（v1 可簡化為等寬公式樣式，Phase C 再上渲染器）。

## 7. 檢視模式

- 大綱視圖（Ctrl+O）：三模式切換（純圖/純大綱/並排）；大綱中 Tab/Enter/Shift+Tab 同樣可編輯，雙向同步。
- 專注模式：隱藏全部 chrome 只留畫布；Esc 退出。
- 演示模式：全螢幕逐分支播放，單擊下一步；右鍵選單（從當前節點開始/跳結尾/退出）；可換演示背景。
- 小地圖：右下角開關，縮圖+紅色視野框可拖曳。
- 分屏模式（Phase C）：心智圖 + 參考文件（pdf/網頁）並排。

## 8. 首頁儀表板

- 側邊欄：新增文檔｜最近編輯｜我的心智圖｜團隊協作（佔位）｜我的分享（佔位）｜我的收藏｜資源回收筒
- 主區：搜索（全文檢索：跨文件搜標題+節點文字）｜新建卡（虛線 + 卡）｜文件卡片格（縮圖、標題、更新時間；右鍵/⋯選單：開啟/改名/複製/收藏/刪除→回收筒）
- 回收筒：還原/永久刪除。
- 範本庫：分類（教育學習/網站工具/生活娛樂/行業分類/個人規劃/讀書筆記/商務職場/家譜族譜）；內容原創。

## 9. 匯出/匯入

- 匯出彈窗 6 格式卡片：JPG｜PNG（可選透明/帶背景）｜PDF（列印管道）｜WORD（.doc 大綱結構）｜TXT（縮排大綱）｜MINDFLOW（原生 JSON）
- HD 選項：邊距預設 80、渲染比例預設 200%
- 匯入：原生 JSON、TXT/Markdown 縮排大綱。
- 歷史版本：本機快照（每次重大變更/定時），列表+預覽+還原。

## 10. 渲染規格（LIVE_DOM_FACTS）

- SVG 為主的導圖渲染（節點可用 HTML div 混合，視覺需一致）：分支線寬按層級 4→3→2→1；有機貝茲/弧曲線；摺疊圓圈 r≈7.5。
- 文字 14px 基準，中文 fallback 系統字型棧。
- 縮放範圍建議 20%–400%；fit 預設留邊。

## 11. 分階段

- **A（已在做）**：核心引擎（模型/undo/佈局/渲染/基本互動/自動存檔）
- **A-fix**：快捷鍵對齊本 SPEC §1（Space 編輯、左鍵平移、Ctrl+左鍵框選、Shift+Tab 上級、Ctrl+/、Ctrl+Delete 分解、Alt+↑↓、Ctrl+D、Shift+↑↓）
- **B（並行 4 條）**：B1 主題系統+樣式面板+文字工具列；B2 六佈局+結構覆蓋+一鍵整理；B3 關聯線+概要+備註+連結+圖片+圖示+懸浮節點+格式刷；B4 首頁儀表板完整版+匯出匯入+全文檢索+範本庫
- **C**：大綱視圖、專注/演示模式、小地圖、歷史版本、尋找取代、公式、貼紙（Codex 生圖）、快捷鍵面板、分屏
- **D**：AI 介面層、白板模式、流程圖（另立專案級任務）
