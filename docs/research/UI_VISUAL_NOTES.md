# GitMind UI 視覺規格筆記（來源：官方教學 GIF 逐幀觀察)

> 本文件僅記錄從 GitMind 官方教學頁面（apowersoft 圖床）之示範 GIF 中，逐幀抽樣觀察到的**視覺事實**（按鈕順序、選項名稱、色值估計、形狀描述），供工程師複刻功能/佈局參考。
> **不包含**任何原始圖片、素材或程式碼，所有顏色皆為以 PIL 對截圖像素取樣後的十六進位估值（因 GIF 為有損壓縮 + 抗鋸齒，數值僅供參考，非官方色票)。
> 凡是看不清楚、沒有在抽樣幀中出現、或推測性的內容，一律標注「不確定」，未做任何編造。
>
> 分析環境：所有 GIF 畫面尺寸皆為 **1300×600 (或 601) px**，推測為固定視窗寬度錄製的教學截圖。
> 取樣方法：每支 GIF 抽取第 1 幀、25%、50%、75%、最後一幀（共 5 幀/支）另存 PNG，逐張人工讀取；對關鍵區域另外裁切放大 2–8 倍後再讀取；顏色使用 Python Pillow `getpixel()` 取樣。

## a. 編輯器 Chrome（整體外觀）

來源：`how-to-use-gitmind-tw-1031-2.gif`、`-5.gif`、`-8.gif`、`-24.gif`（2023/01 版本）等多支 GIF 的第 1 幀。

### 版面分區
整個編輯器畫面由上到下、由左到右分為：
1. **左上角資訊列**（懸浮於畫布上的白色圓角小卡片，非通版頂欄）：
   - `‹` 返回箭頭圖示
   - 文件名稱（如「未命名」「文檔」，可編輯文字）
   - 分隔線 `|`
   - 儲存狀態圖示（小圓圈打勾/雲朵圖示，觀察到會在「最近儲存 HH:MM」→「儲存成功」→「自動儲存所有內容」之間切換文字，具體圖示含意不確定）+ 時間戳文字，灰色小字
2. **頂部中央工具列**：獨立的白色圓角浮動長條（非貼齊視窗頂部），左右兩側與畫布之間有留白，工具列本身有淡淡陰影
3. **右上角操作區**（另一個獨立白色圓角浮動卡片）：
   - 分享圖示（早期版本為純圖示 icon；`tw-1125-*` 及 `-24` 系列版本顯示為**橘色實心藥丸按鈕**，文字「分享」白字）
   - 匯出/開新視窗圖示（方框+箭頭）
   - `···` 更多選單圖示
4. **右側可收合面板**：點擊工具列最後一顆「魔法棒」圖示、或選中節點後某些操作，會從右側滑出白色面板，內有 4 個分頁：**樣式｜主題｜佈局｜圖示**（見下方 b、c、d 章節），面板右上角有 `×` 關閉鈕
5. **右下角浮動圓形按鈕**：畫布右上方（工具列下方）有一顆獨立的白色圓形懸浮按鈕，圖示為「魔法棒+星星」，滑鼠移上會顯示深色 tooltip「樣式 / 更改節點樣式」（來源：`-16.gif` 第 28 幀）
6. **畫布**：大片留白區域，节点與連接線置中或置左顯示
7. **左側**：預設情況下**沒有任何常駐面板或側邊欄**（未觀察到左側工具列、圖層列表等），僅在特定功能（如大綱視圖）啟用時，畫布下方會出現額外浮動控制條

## d. 樣式面板（樣式 tab）★

來源：`-15.gif`（第 54 幀）、`-17.gif`（第 0、63、127、191、254 幀，本章節主要來源）

面板由上到下依序為（選中一個節點時顯示）：

1. **形狀** — 兩個下拉：
   - 節點外形下拉：展開後為 **2 欄 × 5 列 = 10 種形狀**（見下表）
   - 填色下拉：色塊 + 箭頭，展開內容與文字顏色選擇器相同的 80 格網格（未重複截圖驗證，推測共用同一色票元件）
2. **圓角** — 一條水平滑桿（左側橘紅色填充軌道、右側灰色軌道、圓形滑鈕），數值方塊顯示於右側（觀察到 0 與 13 兩種狀態）
3. **邊框** — 三個下拉：線型（—）、顏色（色塊）、寬度（如「0px」）
4. **連接線** — 四個下拉：線形/轉折樣式（⌐C 圖示）、顏色（色塊）、線型（—）、寬度（如「2px」）
5. **架構** — 見上方「c. 佈局選單」章節（圖示下拉 + 向右/向左/平衡）
6. **節點間距** — 重置圖示 + 範圍下拉「全部節點」；「水平間距」「垂直間距」各一組滑桿+數值

## e. 節點視覺細節

### 根節點（中心主題）
- 預設主題：實心品牌橘 `#F58220` 圓角矩形，白色粗體文字，字級明顯大於子節點
- 其他主題可能為：白底黑框（雙向彩虹主題）、實心其他色（金黃/靛藍等）、純白圓角矩形+彩色框
- 觀察到的圓角半徑不一（依主題差異：從近乎直角到全膠囊形都有）

### 二級節點（分支主題）
- 預設主題：淺灰 `#E5E5E5` 圓角矩形填色、黑字、無外框
- 彩虹主題：白底 + 對應分支色的外框線（2px 左右），黑字
- 純色填充主題：與根節點同形狀但用該分支專屬色實心填滿，白字

### 三級（葉）節點
- 預設無外框、無填色，僅純文字（黑字），以一條細線與父節點相連
- 部分主題中葉節點文字會依分支繼承對應色（未在預設主題中觀察到，彩虹主題也多半仍是黑字+彩色線）

### 選取 / 互動狀態
- **選中**：節點外圍出現 2px 橘色圓角外框，略微外擴於節點本身邊界（與節點形狀保持一致的圓角/形狀）
- **編輯中**：節點文字顯示藍色系統文字選取反白（瀏覽器原生選取色），節點外框變為橘色
- **Hover/選中時右上角**：浮現一個小型灰底白色圓形 `···` 按鈕（更多操作入口）
- **拖曳排序中**：被拖曳節點顯示為半透明、色調著色的「幽靈」外形跟隨游標（手形 cursor 圖示，含黃色小手提示動畫），目的地位置出現占位外框
- **調整大小**：節點右側邊緣浮現一個黃色雙向箭頭手柄圖示（教學片用以提示可拖曳調整節點寬度）
- **自由主題（自由節點）**：以半透明橘色疊加於節點上表示「未連接」狀態，與旁邊節點之間以一個小圓圈 `⊖`（減號）圖示表示可移除的暫時連結點（來源 `-8.gif` 第 39 幀）

### 連接線
- 預設主題：深灰 `#333333`，平滑貝茲曲線，多個同層子節點會在靠近父節點處先合併成一個共同的「大括號」彙聚點再各自岔開（類似手寫大括號 `{` 效果）
- 彩虹主題：各主分支（含其所有子孫）沿用同一色相，曲線風格不變
- 若「架構」切換為組織圖/魚骨圖等：連接線變為**直角折線**，不再是平滑曲線

### 關聯線（節點間自由連結，非父子關係）
來源：`-25.gif`（第 293 幀）、`-26.gif`

- 顏色：橘紅 `#FE5723`（取樣值 254,87,35）
- 形狀：**折線（非曲線）**，觀察到的樣本為兩段式折角
- 端點：選取狀態下兩端各有一個小方形控制點（橘色空心方框）
- 箭頭：靠近目標節點的一端有實心小三角形箭頭
- 文字標籤：線段轉折處可放置文字（預設提示「按"空白鍵"添加文本」），標籤文字亦為橘色，範例中顯示「關係線」三字

### 概括（摘要括弧）
來源：`-27.gif`（第 74 幀）、`-28.gif`（第 67 幀）、`-29.gif`（第 175 幀）

- 主要樣式：藍色系「大括號 `{`」曲線（非直角），涵蓋所選的一個或多個相鄰同層節點，括弧尖端向右延伸連接到一個「概括N」的標籤節點
- 「概括N」節點：實心中藍色 `#0874B0`（取樣值 8,116,176）圓角矩形，白字，樣式類似按鈕
- 括弧可只涵蓋單一節點（`-28.gif` 範例：僅框住「分支主題1」）或多個節點（`-27.gif` 範例：框住 3 個分支節點）
- 另觀察到一種「未選中節點」的空狀態（`-29.gif` 第 175 幀）：右側樣式面板顯示一隻粉耳白色卡通吉祥物插圖 + 文字「需要先選中節點，才能調整樣式哦～」；此時概括括弧顯示為**洋紅色點狀直線**而非藍色實心大括號，可能代表「選取範圍指示線」與「已建立的概括括弧」是兩種不同的視覺元件（不確定，需再驗證）

## f. 對話框 / 彈窗

### 匯出（Export）對話框 ★
來源：`tw-1125-5.gif`（第 18、25 幀）

- 深色半透明遮罩覆蓋整個畫面（估算約 50% 黑，取樣 `#7B7B79` 為遮罩+底層混合值）
- 白色圓角卡片置中，內容：
  1. 標題「匯出」（左上）+ `×` 關閉鈕（右上）
  2. 提示文字「* 點擊「匯出」下載」
  3. 一整排 **6 個格式選項**，每個為「彩色圖示 + 下方文字標籤」：
     - **JPG**：紫色圖示
     - **PNG**：金黃色圖示
     - **PDF**：紅色圖示（文件圖示，左上角 "P" 字樣）
     - **WORD**：藍色圖示（文件圖示，左上角 "W" 字樣）— 範例中預設/當前選中此項（橘色外框標示）
     - **TXT**：青色圖示
     - **GITMIND**：橘色圖示（GitMind 自有格式，圖示為互扣環狀圖形，近似官方 logo 造型）
  4. 底部兩個按鈕：「取消」（淺灰底 `#F4F3F3` 圓角膠囊）｜「匯出」（橘色 `≈#F58220` 圓角膠囊，主要行動按鈕）
- 點選任一格式圖示時，該圖示外框變為橘色高亮（單選狀態）

### 引入心智圖（Import Mind Map）面板
來源：`-2.gif` 第 59 幀

- 由右側滑入的白色面板（非全螢幕遮罩對話框，是可與畫布並存的側邊欄）
- 標題「引入心智圖」+ `×` 關閉
- 搜尋輸入框（左側放大鏡圖示）+ 右側橘色「搜索」按鈕
- 提示文字「沒有找到合適的? 試試"連結引入"」（「連結引入」為橘色可點擊文字）
- 檔案列表，每列：圖示（資料夾為橘色開啟資料夾圖示；文件為灰色文件圖示）+ 檔名文字
  - 範例列表項：資料夾、文檔1、文檔、人生規劃、思維工具匯總

### 尋找 & 取代（Find & Replace）面板
來源：`-12.gif` 第 84 幀

### 大綱視圖切換 + 底部浮動控制條
來源：`-18.gif` 第 72 幀
