## 快捷鍵完整表（官方 shortcuts.html，Windows）

**節點操作**：Tab=插入下級節點｜Enter=插入同級節點｜Shift+Tab=插入上級節點｜Ctrl+/=展開/收合｜Delete=刪除節點(含子節點)｜**Ctrl+Delete=刪除但保留子節點**（ADDENDUM 定案，非 Shift+Delete）｜Shift+Delete=刪除選中節點(官方文字，語意未定案)｜Alt+↑/↓=節點上移/下移｜Ctrl+左鍵框選=多選｜Shift+↑/↓=選取上/下同級節點｜Ctrl+Alt+C/V=複製/貼上節點樣式｜**Ctrl+D=複製節點**（同時官方另一分類標為「清除樣式」，是官方頁面本身瑕疵，非查證誤差；建議依 context 分流）

**基本操作**：Ctrl+Z=復原｜Ctrl+Y=重做（無 Ctrl+Shift+Z 替代）｜Ctrl+C/V/X=複製/貼上/剪下｜Ctrl+S=儲存｜Ctrl+R=重新整理

**樣式設定**：F6=換主題｜Ctrl+P=開啟主題面板｜Alt+Y=開啟樣式面板｜Ctrl+D=清除樣式（見上方衝突）

**文字編輯**：Shift+Enter=換行｜Space=進入編輯/編輯關聯線文字｜Ctrl+B/I/U=粗體/斜體/底線｜Ctrl+G=格式刷｜Ctrl+數字鍵=加優先順序（Ctrl+1=優先級1…）｜Ctrl+Shift+>=放大字級｜Ctrl+Shift+<=縮小字級

**插入功能**：Ctrl+Alt+K=插入連結｜Ctrl+Alt+M=插入備註｜Ctrl+Alt+T=插入概要｜Alt+P=插入圖片｜Alt+I=插入圖示｜F4=插入關聯線｜Ctrl+Alt+R=插入評論

**畫布調整**：Ctrl+0=重設縮放｜Ctrl+滑鼠滾輪=縮放畫布｜Ctrl+Shift+L=整理佈局｜Ctrl+O=大綱視圖｜滑鼠左鍵拖曳=平移畫布｜F11=全螢幕｜Ctrl+Alt+F=適應整個畫布(fit view)｜Ctrl+Shift+R=置中回主主題

**進階功能**（官方僅 3 條，多次查證一致）：Shift+Alt+O=開啟協作｜Shift+Alt+H=歷史版本｜Shift+Alt+F=自由/懸浮節點切換

**官方快捷鍵頁「查無」但其他頁提及、確實存在的鍵**：Ctrl+F=尋找與取代（教學頁提及，未收錄進快捷鍵表）｜Esc=退出專注模式（同上）。**確認不存在**：F2 重新命名節點、純方向鍵導覽節點、Ctrl+A 全選（未見任何來源，"···"選單裡的全選才是 Ctrl+A，畫布右鍵選單有列出）。

**未定案/存疑**：Mac 版是否用 Cmd 取代 Ctrl（無官方說明）；Web 版與桌面版快捷鍵是否有差異（無官方說明）。

## 主題（Theme）與樣式面板

- 右側面板 4 分頁：`Style │ Theme │ Layout │ Icon`（節點選取後彈出，也可點頂部工具列「魔杖」直接開啟停在 Theme）
- Theme 分頁 = `Theme` + `Background` 兩個子分頁。Theme 子分頁三層分類：**Recommended（可 Pin 置頂,最多 6 個／Set as default）／Custom（需 Pro）／Purchased（Pro 徽章,需 credits）**
- **主題無官方命名**，只有縮圖，clone 需自建命名。官方文案將主題分三種情境：深色系(簡報用)／日記筆記風／繽紛多彩系(簡報用)
- 觀察到的實際配色範例（供設計參考，非官方名稱）：水彩薄荷綠、極簡淺藍、秋色暖棕橘（分支各自不同色+同色連接線）、奶油+教育塗鴉、藍橘雙色藥丸outline、灰階黑白outline、深色星空(`#0B0B2A`底+橘色星雲)、紫紅彩虹
- Background 子分頁：`Random Background`按鈕｜5色純色快選+更多色票｜`Recommended`背景庫(5頁,每頁約6張)｜自訂上傳(Custom,需帳號權限)｜`Insert watermark`勾選框
- **Style 分頁完整控制項**（節點/連接線樣式）：
  - `Shape`：**固定10種**（小圓角矩形、大圓角矩形、窄藥丸、寬藥丸、更大圓角矩形、底線樣式underline、圓形、橢圓、菱形、平行四邊形）+ 填色下拉
  - `Radius`：滑桿+數值框，**預設 6px**
  - `Border`：線型(5種：實線/細點虛線/中段虛線/點劃線/長虛點劃線)+顏色+**寬度(0/1/2/3/4/5px，6階)**
  - `Line`(連接線)：形狀下拉(推測curved為主,未100%驗證選項)+顏色+線型(同Border 5種)+**寬度(同Border 0-5px，預設3px)**
  - `Structure`：方向下拉，**預設 Right**（其他選項名稱官方未列出逐字清單，存疑，需實測）
  - `Node Spacing`：Horizontal/Vertical 兩條滑桿，**皆預設 30**，範圍下拉預設`All nodes`
  - 色票元件（全站共用）：10欄hue×7列tint/shade + Default + Recent + More Colors連結
- 浮水印完整規格：文字**上限30字元**（預設"GitMind - Making Ideas Count"）｜顏色｜Rotation**恰好3選項**(Left/Right/Horizontal)｜Transparency滑桿0-100｜Size滑桿(字級px)
- 文字/字型工具列（節點上方獨立浮動列，非Style面板）：字型下拉、字級下拉(見過14/24/36)、B/I/U/S(刪除線)、Font color、Fill color(反白螢光)、對齊、行距、格式刷。支援局部文字格式化。
- **確認無Canvas Grid（網格）選項**——兩份官方專頁+全部截圖一致缺席，不需實作grid overlay

## 佈局（Layout）清單

官方繁中 FAQ 逐字列出 **6 種全域佈局**：① 心智圖 Mind Map（中心發散）② 邏輯結構圖 Logic Chart（上下分佈，因果/流程）③ 時間軸 Timeline（有Vertical/Horizontal子方向，未見完整清單）④ 組織結構圖 Org Chart（官方文中也稱「平衡圖」，用詞不一致）⑤ 目錄結構圖 Tree Chart（多層資訊架構）⑥ 魚骨圖 Fishbone（因果分析）。另有 **Balanced Map 平衡圖**（左右均分分支，優缺點對比用）僅見於行銷頁，是否為第7種獨立佈局待查證。

切換入口：全域佈局＝右側「樣式」→「佈局」；單節點局部佈局＝選中節點→「樣式」→「結構」（方向選項名稱未查到，需實測）。流程圖模式另有獨立的「排列」面板（位置/角度/方向/排列方式）。

畫布右下角固定控制列：縮小/放大按鈕、全螢幕、**導航器/小地圖**(紅框拖動視野)、快捷鍵說明入口。**縮放百分比範圍官方未公開**。大綱視圖三模式：純心智圖／純大綱／心智圖+大綱並排，共用Tab/Enter/Shift+Tab/Shift+Enter快捷鍵。演示模式：滑鼠單擊翻頁、右鍵節點「從當前節點演示」、右鍵可跳到結尾/退出、可更換背景；iPad不支援。分屏模式：右下角，可上傳pdf/doc/docx或開網頁與心智圖並排。專注模式：工具列「專注」按鈕進入，Esc或右上角「退出」離開。

## ADDENDUM 三大關鍵補漏（詳見 ADDENDUM.md）

2. **定價表混淆已釐清**：`gitmind.com/pricing`官方三層表（Basic免費/Monthly $9或Annual $4.08/3-Year $79）才是正確資料；此前提到的「5層方案+AI credits 2000/4000/5000」其實來自完全不同的產品`gitmind.ai`（GitMind Chat聊天助理），必須排除，避免SPEC誤植錯誤定價結構。
3. **刪除鍵定案+多項存疑項目撤銷**：`Ctrl+Delete`=刪除但保留子節點、`Delete`=刪除含子節點（採用edit-node.html官方逐字說法定案）；「插入附件」應從SPEC移除（查無此獨立功能，實為分屏模式的參考文件上傳）；「節點編號」存疑項目撤銷，併入既有Priority Icon規格（並非獨立自動編號功能）。
