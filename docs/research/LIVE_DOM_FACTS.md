## 渲染技術（範本檢視器實測）

- **整張導圖 = 單一 SVG**（無 canvas、無 HTML div 節點）：148 paths / 17 texts / 103 g（17 節點的圖）。
- 分支線 = SVG path，含**橢圓弧（A 指令）**營造有機曲線感，例：`M-24.866 0 L-24.866 0 A136.134 249.392 0 0 0 -161 -249.392`。
- **線寬按層級遞減**：4（主幹）→ 3 → 2 → 1（末梢），這就是「線條由粗到細」的實作。
- 節點群組用 g + transform 定位（座標相對父群組）。
- 摺疊/展開指示 = 小圓 path（r≈7.5），fill 用畫布背景色 + 邊框。

## 該範本主題（粉紅主題）具體參數

- 畫布背景：`#FDE0DC`（rgb 253,224,220 粉紅）
- 根節點：填色路徑（圓角矩形，C 曲線畫角），fill `#DAEEF3` 淡藍，文字深藍
- 分支調色盤（每條一級分支一色，子孫繼承）：`#7030A0` 紫、`#E36C0A` 橘、`#00B050` 綠、`#92D050` 淺綠、`#00B0F0` 天藍、`#002060` 深藍、`#4BACC6` 青
  （備註：這組就是 Office 經典調色盤,主題系統應以「branchPalette 陣列」實作）
- 文字：Arial 14px weight 400；二級節點文字色 = 分支色；末端節點文字 `#444` 左右 + 分支色底線
- 未讀/灰色輔助元素：`rgb(186,186,186)`
- hover 強調橘：`#ffa261`（品牌色系）
