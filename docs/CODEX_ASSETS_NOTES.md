# Codex Assets Notes

本次新增的貼紙與 favicon 均為針對本專案手工繪製的原創 SVG，不含外部圖庫、現有產品圖標、文字圖示或 emoji。

## 貼紙規格

- 路徑：`assets/stickers/<category>/<name>.svg`
- 分類：`business`、`education`、`technology`、`expressions`、`travel`、`weather`
- 數量：每類 6 張，共 36 張
- 畫布：`128 × 128` viewBox
- 風格：圓潤扁平造型、主要輪廓 2px、深灰描邊、馬卡龍色系
- 主要描邊：`#554F5B`
- 主要色票：`#F4A7A0`、`#F4B78F`、`#FFE28A`、`#A9D8C8`、`#AFCDF3`、`#C9B8E8`

`assets/stickers/manifest.json` 以英文分類為 key；每筆包含全域唯一 `id`、繁體中文 `name` 與專案相對 `file` 路徑。

## Favicon

`assets/favicon.svg` 以中心節點連接三個分支節點呈現心智圖意象，主節點使用品牌橘 `#F17E2E`。圖形為獨立原創設計。
