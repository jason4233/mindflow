# ARROWS 方向鍵導覽交付紀錄

## 實作

- 無修飾 `↑`、`↓`、`←`、`→` 分別註冊為四向節點導覽 action。
- 導覽只使用目前 `positions` 中的可見節點，不依賴佈局名稱或樹狀父子關係。
- 以當前節點中心為原點，候選需位於指定方向左右各 45° 的 90° 圓錐內。
- 距離分數為 `軸向距離 + 偏軸距離 × 2`；同分時依偏軸距離、軸向距離排序。
- 懸浮節點渲染時會把自由座標回寫同一份 `positions`，因此自然參與候選排序。
- 未選取時，任意方向鍵只選中根節點。
- 編輯或表單焦點中不攔截方向鍵；`Shift+↑/↓` 原有同級選取綁定未變。
- 快捷鍵說明面板新增四向節點導覽。
